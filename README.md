# Fit-Check

Fit-Check is a responsive workout website where users can browse workouts, see workout details, and manage their workout plan.

## Technologies Used

1. Next.js
2. React
3. Tailwind CSS
4. JavaScript
5. Context API
6. REST API

## Key Features

1. Browse workouts
2. View workout details
3. Add workouts to My Plan
4. Save workouts
5. Sort workouts
